    主題工坊

    存成自己的主題

    內建主題只換配色，不動你調好的字型和版面。自己存的主題會把顏色、字型、版面和自訂 CSS 一起記住。

    匯入與匯出

    色碼欄可以直接貼 #rrggbb、rgba(…) 這類 CSS 顏色。

    ttf / otf / woff / woff2，只存在這個瀏覽器
    翻頁方式

    分頁模式：點畫面左右兩側或按方向鍵翻頁，點中間收起／叫回工具列。

    會跟著主題一起儲存。可用的選擇器：.bk-body 整段內文、p h1 em blockquote 等一般標籤、.bk-q 引號文字、#topbar #botbar #panel 介面。書本樣式設成「主題優先」時，蓋不過去的屬性請加 !important。
